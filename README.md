# agents.md

The instructions I use with coding agents.

My agent skills are in [frantss-skills](https://github.com/Frantss/frantss-skills).

## Installation

```sh
curl -fsSL https://raw.githubusercontent.com/Frantss/agents.md/main/AGENTS.md -o AGENTS.md
curl -fsSL https://raw.githubusercontent.com/Frantss/agents.md/main/ORCHESTRATION.md -o ORCHESTRATION.md
```

[ORCHESTRATION.md](ORCHESTRATION.md) needs magpie with Claude Max and OpenCode Go signed in, and herdr-core's `hc`. To configure magpie and install the hc templates, clone this repository and run:

```sh
./magpie/setup.sh
```

The templates stay linked to the clone, so keep it in place.
